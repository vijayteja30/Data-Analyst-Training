"""
Version Control: Github Commands

Must Know commands:
1.  git init --> consider folder as a git repository in local and then to push it to remote repository
2.  git status --> check the status of the repository
3.  git branch --> check the branches in the repository
4.  git checkout --> switch between branches
5.  git diff --> check the differences between files
6.  git diff HEAD --> check the differences between working directory and last commit
7.  git add --> stage the changes for commit
8.  git commit --> commit the staged changes
9.  git stash --> temporarily save changes that are not ready to be committed
10. git fetch --> fetch the changes from remote repository
11. git pull --> fetch and merge the changes from remote repository (git fetch + git merge)
12. git merge --> merge branches
13. git rebase --> reapply commits on top of another base tip
14. git push --> push the changes to remote repository
15. git tag --> create a tag for a specific commit
16. git reset --> undo changes
17. git revert --> create a new commit that undoes the changes of a previous commit
18. git cherry-pick --> apply the changes introduced by some existing commits
19. git bisect --> find the commit that introduced a bug
20. git log --> view the commit history
21. git blame --> show who modified each line of a file
22. git clone --> clone a remote repository to local
23. git remote --> manage remote repositories
"""
